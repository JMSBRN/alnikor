# Шпаргалка Алникор

Интерактивная визуализация продуктов Алникор и Pet’s Brunch: вкладки по животным, этапы «Программы 15000+», блок про отёл, график лактации, три технологии (хелаты, рубцовая защита, пролонгированное действие) и формы ввода.

Сайт: `https://<логин>.github.io/<имя-репозитория>/` — публикуется автоматически при каждом изменении в ветке `main`.

## Как поправить

| Что меняем | Файл |
|---|---|
| Продукты, дозы, польза, этапы, вкладки, классы Pet’s Brunch | `data.js` |
| Тексты блоков «Отёл», «Технологии», «Формы ввода», ориентиры надоев, контакты, цвета | `index.html` |

Прямо на GitHub: открыть файл → значок карандаша → внести правку → **Commit changes**. Через 1–2 минуты сайт обновится (ход публикации — вкладка **Actions**).

> Если меняли структуру `data.js` (новые разделы, калькуляторы), в `index.html` увеличьте номер в строке `data.js?v=3` → `v=4`, чтобы браузеры не взяли старую версию из кэша. После правки нажмите Ctrl+F5.

### Пример: добавить продукт

В `data.js`, в массив `window.P`, добавить строку:

```js
{a:'cattle',g:'peak',n:'Новый продукт',d:'50 г / сут',w:'Что это',b:'Какая польза',t:['chel']},
```

- `a` — вкладка: `cattle`, `poultry`, `dogs`, `cats`, `small`, `raw`, `hygiene`
- `g` — для КРС этап: `calf`, `young`, `dry`, `transit`, `peak`, `keep`, `fix`; для остальных — название группы
- `t` — метки: `chel` (хелаты), `rumen` (рубцовая защита), `prol` (пролонг) или `[]`

### Проверить локально

Открыть `index.html` в браузере — сборка не нужна.

## Первая публикация

Settings → Pages → Source: **GitHub Actions**. Дальше всё автоматически.
